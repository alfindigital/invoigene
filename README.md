# Invoigene — Nota & Invoice Gratis untuk UMKM

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![React](https://img.shields.io/badge/React-18-61dafb?logo=react)](https://react.dev)

Buat nota dan invoice profesional dengan cepat, langsung di browser. Ideal untuk UMKM, freelancer, dan pedagang kecil. Tanpa akun, tanpa biaya, data tersimpan lokal.

---

## Fitur

- 🧾 **Buat Invoice/Nota** — Form lengkap, tampilan profesional
- 🖨️ **Print & PDF** — Cetak atau ekspor ke PDF langsung
- 💾 **Simpan Lokal** — Data tersimpan di browser, tidak ke cloud
- 📋 **Riwayat Nota** — Akses nota yang pernah dibuat
- 📱 **Mobile First** — Optimal di HP untuk kebutuhan di lapangan
- 🌐 **Offline** — Tidak butuh koneksi internet

---

## Quick Start

```bash
git clone https://github.com/alfindigital/invoigene.git
cd invoigene
npm install
npm run dev
npm run build
```

---

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
